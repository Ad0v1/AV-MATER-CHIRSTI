
# AV-MATER-CHIRSTI

Sistema Web de Control de Asistencia Escolar

## Objetivo
Digitalizar el registro y seguimiento de asistencia de los estudiantes del colegio Mater Christi.

## Funcionalidades
- Autenticación y roles
- Gestión de estudiantes
- Registro de asistencia
- Reportes y consultas
- Auditoría de registros

## Trabajo colaborativo
- main: versión estable
- develop: integración
- feature/*: desarrollo individual

## Calidad
Pull Requests, revisiones de código y pruebas automatizadas mediante GitHub Actions.
