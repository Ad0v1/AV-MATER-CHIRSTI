# Manual del apoderado

> **Estado: PROPUESTA.** En esta versión no hay materiales, tareas ni archivos para el apoderado.

## Qué puedes ver en el curso

- Si entras a **Clases**, **Lecturas** o **Tareas**, la pantalla muestra un mensaje de error o indica que esa sección no está disponible para tu rol. Es lo esperado: el apoderado no tiene acceso a los materiales, a las tareas ni a los archivos de entrega.

Las calificaciones y los estados de tus hijos llegarán con el módulo de calificaciones, que todavía no está disponible.
